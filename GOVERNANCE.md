# Governance

## Who decides

Fundamental is led by Sounds Global B.V., which holds the copyright and the "Fundamental" name. The maintainers review and merge changes and decide on proposals. Once there are maintainers from outside the company, the project can move to a neutral foundation.

## How the framework changes

- Anything larger than a fix starts as an issue describing the problem, so the design is agreed before the code is written.
- A breaking change to a public API is marked **Breaking** in [`CHANGELOG.md`](CHANGELOG.md), with what to write instead.
- An error code keeps its meaning forever; a retired code is never reused.
